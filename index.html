Bash Command I Have learnt

1. touch

File creation

The touch command is used to create a new empty file in the current directory. It can also be used to update the access and modification timestamps of an existing file.

It's one of the simplest ways to create a new file in the terminal.

Syntax: touch file name

Example: touch notes.txt

Output:
notes.txt

2. mkdir

Directory creation

The mkdir command is used to create a new directory in the current location.

It's a simple way to organize files and create a structured filesystem.

Syntax: mkdir directory_name

Example: mkdir projects

Output:
projects/

3. ls

List directory contents

The ls command is used to list the contents of a directory.

It's a fundamental command for navigating and exploring the filesystem.

Syntax: ls

Example: ls

Output:
notes.txt projects/
